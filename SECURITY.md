# Security Policy

## Reporting a vulnerability

Please do not publish security vulnerabilities in public issues. Contact the repository owner privately with reproduction steps and the affected component.

## Secrets

Secrets are supplied through environment variables. Do not commit `.env`, database files, credentials, tokens, or private keys.

## Data

The seed dataset is synthetic/demo data. Do not use this repository with real patient or other sensitive health data without appropriate security, privacy, governance, and compliance controls.
